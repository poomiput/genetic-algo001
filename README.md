# Genetic Algorithm (GA)

**Genetic Algorithm** เป็นวิธีการทาง algorithm ตัวหนึ่ง เหมือนกับ DFS, BFS, Dijkstra — คือเป็นขั้นตอนวิธี (algorithm) ที่ใช้แก้ปัญหา โดย GA ใช้สำหรับ**หาคำตอบที่ดีที่สุด (Optimization)** เช่น การจัดเส้นทางขนส่งในงาน Logistics

- DFS / BFS → ใช้สำรวจกราฟ
- Dijkstra → ใช้หาเส้นทางสั้นสุด
- **Genetic Algorithm → ใช้หาคำตอบที่ดีที่สุดจากตัวเลือกจำนวนมาก**

## ขั้นตอนการทำงาน

GA เลียนแบบการวิวัฒนาการของสิ่งมีชีวิต ทำงานวนซ้ำเป็นรอบ ๆ (generation) ดังนี้

1. **Initialize** — สุ่มสร้างกลุ่มคำตอบเริ่มต้น (Population) เช่น สุ่มลำดับการส่งของหลาย ๆ แบบ
2. **Evaluate** — ให้คะแนนแต่ละคำตอบด้วย Fitness Function เช่น ระยะทางรวมยิ่งสั้นยิ่งได้คะแนนสูง
3. **Selection** — คัดเลือกคำตอบที่คะแนนดีมาเป็น "พ่อแม่พันธุ์"
4. **Crossover** — ผสมคำตอบพ่อแม่ 2 ตัว สร้างคำตอบลูกตัวใหม่
5. **Mutation** — สุ่มปรับคำตอบลูกเล็กน้อย เช่น สลับลำดับลูกค้า 2 ราย เพื่อให้เกิดความหลากหลาย
6. **Replace** — ได้ประชากรรุ่นใหม่ แล้ววนกลับไปข้อ 2 จนครบจำนวนรอบที่กำหนด

คำตอบที่ดีที่สุดในรุ่นสุดท้ายคือผลลัพธ์ของอัลกอริทึม

## Pseudocode

```python
population = random_population(size=100)

for generation in range(max_generations):
    scores = [fitness(x) for x in population]

    new_population = []
    while len(new_population) < len(population):
        parent1, parent2 = select(population, scores)   # เลือกตัวที่คะแนนดี
        child = crossover(parent1, parent2)             # ผสมคำตอบ
        if random() < mutation_rate:
            child = mutate(child)                       # สุ่มปรับเล็กน้อย
        new_population.append(child)

    population = new_population

best = max(population, key=fitness)
```

## ตัวอย่างการใช้กับงาน Logistics

โจทย์: รถส่งของ 1 คัน ต้องส่งของให้ลูกค้า 5 ราย เรียงลำดับยังไงให้ระยะทางรวมสั้นสุด

- **คำตอบ (Chromosome)** = ลำดับการเยี่ยมลูกค้า เช่น `[3, 1, 5, 2, 4]`
- **Fitness** = ระยะทางรวมของเส้นทางนั้น (ยิ่งสั้นยิ่งดี)
- **Crossover** = ตัดช่วงลำดับจากพ่อ มาเติมด้วยลำดับของแม่ (Order Crossover)
- **Mutation** = สลับตำแหน่งลูกค้า 2 ราย

รันวนหลายร้อยรอบ ลำดับการส่งของจะค่อย ๆ ดีขึ้นเรื่อย ๆ จนได้เส้นทางที่สั้นมาก

ปัญหา Logistics อื่นที่ใช้ GA ได้: จัดเส้นทางรถหลายคัน (VRP), จัดของใส่ตู้คอนเทนเนอร์, เลือกตำแหน่งคลังสินค้า

## พารามิเตอร์หลัก

| พารามิเตอร์ | ค่าที่นิยมใช้ |
|---|---|
| Population Size | 50–200 |
| จำนวนรอบ (Generations) | 500–2000 |
| Crossover Rate | 0.8–0.95 |
| Mutation Rate | 0.01–0.1 |

## จุดเด่น / ข้อควรรู้

- ใช้ได้กับปัญหาที่ตัวเลือกเยอะมากจนไล่เช็คทั้งหมดไม่ไหว
- ไม่การันตีคำตอบที่ดีที่สุดเป๊ะ แต่ได้คำตอบที่ "ดีมาก" ในเวลาสั้น
- ผลลัพธ์ขึ้นกับการตั้งค่าพารามิเตอร์ ควรลองปรับจูนหลาย ๆ ค่า
